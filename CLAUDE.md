# latentmemory

A cognitive prosthesis for the AI era — an antidote to the biggest failure mode of working with LLMs: *epistemic illusion* (the feeling that because an agent explained something clearly in the moment, you now own that knowledge).

## Modeling

If our domain owns a vocabulary, model it as a closed union so the compiler checks we've handled every case. If an outside party owns it, model it as an open set (a non-empty string) and deal with unknown values where the data comes in.
